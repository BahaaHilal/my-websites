## Projects

### 1. Kammat Sounds
**Hand-Tracking Audio Synthesis Interface**

A real-time audio synthesis application that uses camera input and hand gesture recognition to create and control synthesized sounds. This project demonstrates expertise in Web Audio API, computer vision, interactive design, and complex user interface development.

- **Description**: 
  - Shape sound with your hands in real-time using hand-tracking technology
  - Control pitch by moving your hand horizontally (X-axis)
  - Adjust volume by moving your hand vertically (Y-axis)
  - Modify harmonics and tonal richness using pinch gestures
  - Control reverb and spatial effects using hand spread
  - Multiple instrument voices: Rhodes electric piano, atmospheric pads, bells, and bass
  - Includes arpeggiator with 6 different patterns (Up, Down, Bounce, Random, Chord)
  - Built-in drone pad for harmonic foundation
  - Real-time audio looping and recording (up to 8 seconds)
  - 6 musical scales: Em Pentatonic, Am Pentatonic, A Blues, C Major, D Dorian, G Mixolydian
  - Advanced sound shaping with parameter controls
  - Live waveform visualization
  - Real-time meter displays for all gesture parameters
  - Status indicators and performance monitoring

- **Tech Stack**: 
  - HTML5, CSS3 (custom chrome-style UI design)
  - JavaScript (ES6+)
  - Web Audio API (synthesizers, effects, audio processing)
  - MediaPipe or similar hand detection library (camera-based gesture recognition)
  - Canvas API (waveform visualization and graphics)
  - Responsive design with custom control interfaces

- **Key Skills Demonstrated**:
  - Real-time audio synthesis and digital signal processing
  - Hand gesture recognition and motion tracking
  - Interactive parameter control via camera input
  - Audio looping and recording functionality
  - Responsive UI design with retro-style chrome interfaces
  - Audio visualization and real-time data display
  - User experience design for novel input methods
  - Performance optimization for real-time processing

- **Source**: See the `/kammat-sounds` folder in this repository

### 2. Voidform
**Interactive Sound Sculpture & Dual-Hand Atmospheric Engine**

An immersive, experimental audiovisual experience that transforms hand gestures into evolving soundscapes and visual particles. This project showcases creative web development, generative art, spatial audio, and innovative interaction design.

- **Description**: 
  - Dual-hand interactive experience where each hand controls different sound elements
  - Left hand (Terra): Controls bass and grounding frequencies
  - Right hand (Aether): Controls ethereal and atmospheric tones
  - Hand distance measurement creates "Nexus distance" — a spatial parameter that modulates sound
  - Generates evolving particles and visual effects synchronized with audio
  - Multiple musical scales including Aeolian, Phrygian, Hijaz (Arabic scale), Pentatonic, Lydian, Chromatic, and Whole Tone
  - Five distinct sound instruments controlled by individual fingers:
    - Bass: Low-end foundation
    - Bell: Ringing harmonic tones
    - Pad: Smooth atmospheric layers
    - Shimmer: High-frequency crystalline textures
    - Glitch: Digital artifacts and processed sounds
  - Real-time echo/delay effects
  - Configurable reverb and warmth parameters
  - Adjustable particle density for visual density control
  - Optional drone pad for continuous harmonic support
  - Custom HUD display with status information
  - Atmospheric vignette and scanline effects for visual polish
  - Configurable settings panel for real-time parameter adjustment

- **Tech Stack**: 
  - HTML5, CSS3 (dark theme with sci-fi aesthetic)
  - JavaScript (ES6+)
  - Web Audio API (synthesis, effects processing, spatial audio)
  - Canvas API (real-time particle generation and animation)
  - Hand gesture recognition and multi-hand tracking
  - Responsive design with custom UI elements
  - Performance-optimized generative graphics

- **Key Skills Demonstrated**:
  - Generative audio and dynamic sound design
  - Real-time particle system and animation
  - Dual-hand gesture recognition and interaction
  - Spatial audio and 3D soundfield manipulation
  - Advanced Web Audio API techniques (oscillators, filters, reverb, delays)
  - Visual-audio synchronization (audiovisual design)
  - Creative UI/UX for experimental interfaces
  - Performance optimization for real-time graphics and audio
  - Settings/configuration systems for user customization

- **Source**: See the `/voidform` folder in this repository
